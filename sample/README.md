# Sample vault

A fictional vault for trying Home Project Manager. Everything here is generated by `scripts/build-sample.mjs`.

1. From the repo root, run `node scripts/build-sample.mjs`. This refreshes the dates and copies the plugin into `sample/.obsidian/plugins/`.
2. In Obsidian, choose **Open another vault → Open folder as vault** and pick this folder.
3. Trust the vault when asked, then open **Home**.

Don't keep your own notes here: running the script again replaces everything except `.obsidian/`.
